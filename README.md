# Rifqah Sulaiha Portfolio

A cinematic portfolio for **Rifqah Sulaiha**, a BCA student and aspiring game developer with experience in project management, software testing, web development, UI/UX collaboration, creative design, and AI-assisted development.

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL in the browser.

## Production build

```bash
npm run build
npm run preview
```

## SEO and portfolio setup

This project includes:

- canonical metadata for the production URL
- Open Graph and Twitter card metadata
- structured data for Person, WebSite, ProfilePage, and related project content
- robots.txt and sitemap.xml for indexation
- custom 404 page for a cleaner static-hosted experience

The production deployment URL is:

https://rifqah-the-series.vercel.app/

## Content source

Portfolio content is managed in `src/data/portfolio.ts` and the public metadata files under `public/`.
